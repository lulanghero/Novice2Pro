# 2.构建项目

使用 PyCharm 创建一个新的 Python 项目，并为其配置虚拟环境。

项目名称：rag_test

## 2.1 将相关代码拷贝到项目工程中

直接将下载的文件夹中的所有内容复制到新建项目的目录中。

## 2.2 安装项目依赖

在终端运行以下命令安装所需的依赖包：

```batch
pip install -r requirements.txt
```

注意：每个软件包都指定了本次测试所用的固定版本号。本视频使用的 graphrag 版本为 0.3.0（最新）。

## 2.3 创建 GraphRAG 所需文件夹

在当前项目下创建一个所需文件夹 inputs和cache，后续操作均在此目录下进行。

```txt
mkdir input  
mkdir inputs  
mkdir cache
```

## 2.4 初始化 GraphRAG

执行以下命令初始化 GraphRAG 索引结构:

```batch
python -m graphrag.index --init --root ./
```

## 2.5 设置参数

编辑 .env 和 settings.yaml 文件：

提示：直接复制one- api 重构后的阿里通义千问大模型。

## 2.6 优化提示词

运行以下命令对提示词进行调优（适合中文）：

```batch
python -m graphrag_prompt Tune --config ./settings.yaml --root ./--no-entity-types --language Chinese --output ./prompts
```

## 2.7 构建索引

构建完整的知识图谱索引：

```batch
python -m graphrag.index --root ./
```
