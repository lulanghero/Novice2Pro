## 一、项目背景与竞赛契合度

在新冠疫情之后，远程协作逐渐成为软件开发的主流模式，GitHub 已成为全球最重要的开源协作平台之一。
然而，在开源生态持续扩大的同时，新手开发者在进入开源社区时仍普遍面临以下结构性问题：

* 项目选择困难，难以判断项目是否适合自身能力阶段
* 社区健康度不可感知，Issue / PR 活跃度难以解释
* 贡献反馈滞后，个人贡献价值缺乏即时认知
* 学习路径碎片化，缺乏从“新手”到“稳定贡献者”的系统性指导

OpenSODA 大赛提供的 **GitHub 全域日志数据、Top300 仓库历史日志以及 OpenDigger 指标体系**，为从“真实行为数据”出发构建开源教育与激励系统提供了高度契合的数据基础。

---

## 二、项目核心思想（与实现强一致）

Novice2Pro 并不将“某一类数据”固化为系统逻辑，而是采用：

> **“RAG 作为通用知识承载层 + Agent 作为理解与调度层”** 的架构设计。

在该设计下：

* **RAG 系统可以搭载不同类型的知识库**

  * 开源项目行为数据（OpenSODA 数据集）
  * 开源社区结构化指标（OpenRank / OpenDigger）
  * 技术分析、案例研究、学习材料等
* **Agent 不依赖具体数据来源**

  * 只负责如何检索
  * 如何组织上下文
  * 如何以可解释形式输出结果

因此，本项目当前实现即是：

> **面向开源教育场景的通用型 RAG + Agent 智能分析框架**

而 OpenSODA 提供的比赛数据，正是该框架最重要、也是最核心的目标知识源之一。

## 三、系统当前能力（已实现）

### 3.1 可插拔知识库的 GraphRAG 系统（已实现）

系统采用 GraphRAG 方式组织知识：

* 支持将数据构建为：

  * 实体（开发者、项目、行为、指标）
  * 关系（贡献、协作、影响、时序）
* 支持基于问题进行：

  * 高相关事实检索
  * 实体关系路径追溯
  * 行为流程与时序还原

**重要特性：**

* 知识库内容可替换
* 不限定数据领域
* 不依赖固定 schema

这使得系统可以：

* 当前：接入示例/分析型知识库验证能力
* 后续：无缝接入 OpenSODA 官方数据集，构建开源行为知识图谱

---

### 3.2 Agent 驱动的检索与输出编排（已实现）

系统引入 Agent 层，但并不将其设计为“对话机器人”，而是：

> **任务型、分析型 Agent**

Agent 的职责包括：

* 控制 RAG 的检索策略
* 约束输出格式（如【参考资料】）
* 管理 Prompt 与上下文构造
* 避免多轮对话对知识检索的污染

该设计非常适合：

* 学习路径分析
* 项目特征解释
* 行为模式归纳
* 教育与激励场景下的“解释优先”需求

---

### 3.3 OpenAI-Compatible 接口（已实现）

系统对外提供标准接口：

```http
POST /v1/chat/completions
```

具备以下特性：

* 可直接接入前端（如 newchat）
* 可通过 one-api 统一管理模型
* 为后续多 Agent / 多任务系统提供统一调用入口

## 四、与 Novice2Pro 目标的对应关系

本项目当前版本并非完整的平台系统，而是 **Novice2Pro 的核心智能分析引擎原型**。

| Novice2Pro 目标 | 当前系统支撑方式                |
| ------------------- | ----------------------- |
| 新手学习路径理解            | 通过行为与关系检索输出可解释事实        |
| 项目推荐依据              | 通过 RAG 提供项目行为与健康度证据     |
| 贡献价值解释              | 为 OpenRank 等指标提供上下文解释能力 |
| 激励机制设计              | 基于 Agent 输出构建上层规则（规划中）  |
| 多 Agent 协作          | 架构预留，当前以单 Agent 验证能力    |

## 五、系统架构概览

```text
┌──────────────┐
│  Knowledge   │  ← 可替换（OpenSODA / OpenRank / 文档）
│   Sources    │
└──────┬───────┘
       │
┌──────▼───────┐
│   GraphRAG   │  ← 实体 / 关系 / 时序建模
└──────┬───────┘
       │
┌──────▼───────┐
│     Agent    │  ← 检索控制 / 输出约束
└──────┬───────┘
       │
┌──────▼───────┐
│  API Layer   │  ← /v1/chat/completions
└──────────────┘
```

## 八、总结

Novice2Pro 采用 **RAG + Agent 的通用智能架构设计**，通过可插拔知识库机制，为不同开源教育与激励场景提供统一的智能分析能力。

当前实现已验证：

* 架构可行性
* 可解释性优势
* 与 OpenSODA 数据的天然适配性

为后续构建完整的开源教育与激励平台奠定了坚实基础。
